## 组织规则

- 按竞赛 / 年份或届次 / 题号排列 PDF，补充按模型阅读入口。
- 采用 Git blob 哈希与 SHA-256 识别完全相同内容；不按标题删除不同版本。重复项通过索引链接复用。
- 年份和题号依据原始目录、文件名以及重点论文封面；不明确的信息保留“待核实”。目录名“04-25”不表示每个年份均完整，研究生资料没有 2011 年专门目录，2024 年来自重点学习中的两篇论文。
- 解压后的 PDF 为普通 Git 文件，直接保存全文，不使用 LFS 指针替代正文。大型 PDF 可能需要点击下载阅读。
- 原有 PDF 不改写；Word 版本使用 Microsoft Word 导出，原稿同时保留以便核对公式与分页。
- 程序和数据附件保留相对层级；不运行其中的程序。缓存、编译产物、系统隐藏文件及明确的宣传资料不加入新资料。

## 验证范围

- 每个入库 PDF 检查文件头、加密状态、有效页数及首页 / 尾页可加载性；这不等于逐页人工审阅。
